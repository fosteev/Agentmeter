# Эталон стартового префикса (1.7)

Три сессии, в которых раскладка стартового префикса по категориям **посчитана
руками и записана здесь до того, как появился код**. Числа подобраны так, чтобы
каждый блок давал ровно 1000 токенов и всё проверялось в уме.

> `*.expected.json` пересобирать выводом реализации нельзя. Меняется код —
> сверяемся с этой таблицей; меняется таблица — сначала объяснение, почему
> прежний расчёт был неверен, потом код.

Сами `*.jsonl` собирает `scripts/make-prefix-fixture.ts` — он только раскладывает
эти числа по записям нужного формата и добивает блоки до заданной длины в
**байтах UTF-8** (не в символах: у кириллицы это разные числа, и в живых логах
разница вдвое).

## Что считаем

Стартовый префикс — всё, что уехало в промпт до первого ответа модели. Он
кэшируется один раз, а потом перечитывается на **каждом** запросе сессии,
поэтому его цена — не разовая: `recurrentTokens = tokens × число записанных
запросов`. Отсюда и название этапа.

```
prefixTokens = ctx первого записанного запроса     ← единственное измеренное число
             = Σ блоков по категориям
```

Категории и откуда берутся у Claude:

| категория         | источник в транскрипте                      |
| ----------------- | ------------------------------------------- |
| `skills`          | `attachment.skill_listing.content`          |
| `agents`          | `attachment.agent_listing_delta.addedLines` |
| `mcpTools`        | `deferred_tools_delta.addedNames`, имена с префиксом `mcp__` |
| `deferredTools`   | там же, остальные имена                     |
| `mcpInstructions` | `mcp_instructions_delta.addedBlocks`        |
| `memory`          | `nested_memory.content` + `CLAUDE.md` с диска |
| `userTurn`        | текст первой записи `user`                  |
| `system`          | **остаток**: системный промпт и схемы вшитых тулов |

`system` — не оценка, а разность. Всё остальное считается из байтов и потому
оценка; в макете такие числа идут штриховкой.

## Байт на токен

| категория         | б/т  | откуда                                            |
| ----------------- | ---- | ------------------------------------------------- |
| `deferredTools`, `mcpTools` | 2.60 | список имён тулов, стенд: 2.58 и 2.66 на двух разных наборах |
| `mcpInstructions` | 3.68 | блоки инструкций MCP, стенд                       |
| `skills`          | 4.05 | листинг скиллов, стенд                            |
| `agents`          | 4.22 | листинг сабагентов, стенд (4.22 и 4.23)           |
| `memory`          | 4.11 | markdown-документация, стенд по наклону двух точек |
| `userTurn`        | 3.02 | живые логи, 685 пар сессий; стенд даёт 2.51 и 3.45 на двух реальных промптах |

Цифры измерены стендом `scripts/probe/calibrate-prefix.sh` 9 августа 2026 на
Claude Code 2.1.226. Способ — «весы»: известный текст кладётся в `CLAUDE.md`
пустой папки, гоняется `claude -p 'hi' --model haiku`, разница `ctx` даёт точное
число токенов без всякого токенизатора. Прогон стоит цент.

Ратио на категорию, а не одно общее, — не педантизм: список имён тулов плотнее
прозы в полтора раза (2.60 против 4.11), и одна общая константа врала бы на
блоке имён на 50%.

Ратио — свойство токенизатора, а не версии CLI: те же тексты на 2.1.85 и 2.1.226
дали 4.05 и 4.05, 3.68 и 3.68. А вот **размер системного промпта версией
меняется**, и заметно: пустой префикс `-p` вырос с 7772 токенов на 2.1.85 до
7111 на 2.1.226, схемы вшитых тулов — с 10 898 до 14 245. Отсюда правило: ратио
живут в коде, размер системного промпта — только остатком из живых логов.

**У Codex константы не калибровались.** Там другой токенизатор, и до своего
стенда Codex наследует числа Claude. Всё, что посчитано из байтов у Codex, —
оценка с неизвестной систематической ошибкой, и так и помечается.

## Правила счёта

1. `tokens = Math.round(bytes / bytesPerToken)` по блоку целиком.
2. Дележ блока между источниками (серверами MCP) — по долям байтов **имён**,
   разделители не в счёт, остаток раздаётся по наибольшей дробной части, при
   равенстве — по порядку в блоке. То же правило, что в `splitResidual` (1.6):
   переиндексация обязана давать те же цифры.
3. `system` = `prefixTokens − Σ остальных`. Ошибки округления оседают в нём.
4. `system` отрицательным быть не может. Если стал — категории переоценены,
   это ошибка модели, а не повод обрезать по нулю.

## Claude, отложенный режим — `claude-prefix.jsonl`

В наборе есть `ToolSearch`, поэтому схемы тулов MCP в префикс не едут — едут
только имена. `prefixTokens = 30 000`.

| блок              | байт | б/т  | токенов | как                     |
| ----------------- | ---- | ---- | ------- | ----------------------- |
| `skills`          | 4050 | 4.05 | **1000** | 4050 / 4.05            |
| `agents`          | 4220 | 4.22 | **1000** | 4220 / 4.22            |
| `mcpTools`        | 1296 | 2.60 | **500**  | доля блока имён         |
| `deferredTools`   | 1295 | 2.60 | **500**  | доля блока имён         |
| `mcpInstructions` | 3680 | 3.68 | **1000** | 3680 / 3.68            |
| `memory`          | 4110 | 4.11 | **1000** | 4110 / 4.11            |
| `userTurn`        | 3020 | 3.02 | **1000** | 3020 / 3.02            |
| `system`          |      |      | **24 000** | 30 000 − 6000        |

Блок отложенных имён — 2600 байт: десять имён через `\n`, то есть 2591 байт
имён и 9 байт разделителей. Пять имён начинаются с `mcp__serena__` и весят
1296 байт, пять вшитых — 1295. Токенов в блоке 2600 / 2.60 = 1000, делятся по
байтам имён: serena = 1000 × 1296 / 2591 = 500.19 → 500, вшитым остаток 500.

Записанных запросов в сессии **12**, компактов нет. Рекуррентная стоимость
каждого блока — токены × 12: `skills` 12 000, `system` 288 000. Итог по сессии
30 000 × 12 = **360 000** токенов чтения кэша, из которых 80% — системный
промпт со схемами.

## Claude, жадный режим — `claude-eager.jsonl`

`ToolSearch` в наборе нет, записи `deferred_tools_delta` нет вовсе. Схемы тулов
MCP уехали в системный промпт и из транскрипта неотделимы. `prefixTokens = 36 000`.

| блок       | байт | б/т  | токенов |
| ---------- | ---- | ---- | ------- |
| `skills`   | 4050 | 4.05 | **1000** |
| `userTurn` | 3020 | 3.02 | **1000** |
| `system`   |      |      | **34 000** |

`toolsDeferred = false`. Разница с первой сессией — 10 000 токенов на пустом
месте: у serena 23 тула, и жадно они стоят 6007 токенов против 349 отложенных,
в 17 раз дороже (замер стендом на 2.1.226; на 2.1.85 было 5998 против 326 —
цифры устойчивы). Показывать в этом режиме нулевую цену MCP-серверу нельзя —
она не ноль, она просто неотделима, и так и пишется: `system` с пометкой, что
внутри сидят схемы.

## Codex — `codex-prefix.jsonl`

У Codex системный промпт лежит в логе дословно (`session_meta.base_instructions`),
поэтому остатком оказывается ровно обратное — схемы тулов. `prefixTokens = 9000`
(`input_tokens` первого запроса).

| блок          | байт   | б/т  | токенов | источник                        |
| ------------- | ------ | ---- | ------- | ------------------------------- |
| `system`      | 12 330 | 4.11 | **3000** | `session_meta.base_instructions` |
| `memory`      | 4110   | 4.11 | **1000** | AGENTS.md, первый `message`      |
| `userTurn`    | 3020   | 3.02 | **1000** | второй `message`                 |
| `toolSchemas` |        |      | **4000** | 9000 − 5000, остаток             |

Здесь `system` — оценка по байтам, а `toolSchemas` — остаток. У Claude
наоборот. Обе раскладки живут по одним правилам, меняется только то, что видно
в логе.

## Чего в этих фикстурах нет

- Цены компакта: пересборка префикса после сжатия — отдельная статья, 4.4.
- Прироста в середине сессии (сервер MCP подключился позже, `ToolSearch`
  подтянул схемы). Это маржинальная дельта, её считает 1.6.
- Сабагентов: у них свой префикс, свой системный промпт и урезанный набор
  тулов. Складывать с родительским — двойной счёт, развязка в 3.5.
