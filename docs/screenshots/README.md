# Снимки экранов для README (5.5)

Снимаются **из макета**, а не из работающего приложения:

```bash
node scripts/make-shots.js
```

Скрипт поднимает Electron, открывает `design/Agentmeter.dc.html`, находит в нём
экраны по подписям разделов и снимает каждый в свой файл в двойном разрешении.
Всё, что он трогает, лежит в репозитории: шрифты подключаются файлами отсюда же,
а не с Google Fonts, как в самом макете, — без сети вёрстка поехала бы на
системных подстановках молча и правдоподобно.

| файл            | раздел макета         | что на нём                                                          |
| --------------- | --------------------- | -------------------------------------------------------------------- |
| `popup.png`     | 2 · Попап из трея     | три агента, точный процент Codex рядом с оценкой Claude               |
| `today.png`     | 3 · Главное окно      | лента дня, разрезы по часам и проектам                                |
| `task.png`      | 4 · Карточка задачи   | таймлайн, виды токенов, инструменты, файлы                            |
| `breakdown.png` | 5 · Развёртка         | постоянное против разового и совет про неиспользованный сервер        |
| `settings.png`  | 6 · Настройки         | пять групп настроек                                                    |
| `history.png`   | 8 · История           | неделя столбиками и хитмап «день × час»                               |

## Почему из макета

Снимок живого окна показывает настоящие проекты, ветки и первые промпты — то
есть рабочую переписку и чужие имена. Вычистить их нечем, кроме тумблеров
приватности, а они заодно убирают половину смысла экрана: без путей карточка
задачи теряет файлы, без промптов лента теряет названия.

Макет же и есть эталон вёрстки, и состояния в нём расставлены нарочно — два
провайдера сразу, оценка рядом с точным числом, сервер, который не звали ни
разу. Цена решения названа прямо в README: подписи на снимках русские, а
интерфейс приложения — на двух языках.

## Что стоит помнить, если переснимать

- Экраны ищутся по подписи раздела («3 · Главное окно»), а не по номеру строки:
  строки в макете сдвигаются на каждой правке дизайна, подписи держатся.
- Прокрутка страницы и снимок — разные моменты времени. Первый заход выдал шесть
  картинок с шапкой макета вместо шести разных экранов, и каждая была настоящей
  картинкой настоящей страницы; отсюда паузы на перерисовку в `scripts/shots/`.
- `await app.whenReady()` на верхнем уровне ESM-входа Electron висит навсегда:
  он ждёт, пока модуль домчит до конца. Процесс при этом живой, окон нет, вывода
  нет.
