# Скриншоты для README (5.5)

Снимает человек, а не проба: браузер со скриншотами для проверки интерфейса в
этом проекте не гоняется, а картинки для README — это ещё и вопрос того, что на
них попало. Ниже — что нужно и в каком состоянии.

Общее для всех: **тёмная тема** (основная в макете), русский язык, retina
(на macOS снимок окна `⌘⇧4` пробелом — уже 2×). Класть сюда с именами из
таблицы: README ссылается на них ровно так.

| файл             | экран                    | в каком состоянии                                                                                                             |
| ---------------- | ------------------------ | ----------------------------------------------------------------------------------------------------------------------------- |
| `popup.png`      | попап из трея, 400×600   | Работают **два-три агента разных провайдеров**, у одного состояние «думает», у другого «ждёт ответа». Видна полоса лимита Codex с точным процентом и полоса Claude со знаком `≈` — на одной картинке сразу вся честность продукта |
| `breakdown.png`  | вкладка «Развёртка»      | Режим **«за сессию»**, и в списке советов виден хотя бы один сервер MCP, который не звали ни разу. Это главный экран продукта  |
| `today.png`      | вкладка «Сегодня»        | День с 5–10 задачами, одна карточка **раскрыта**: видны таймлайн, виды токенов и инструменты                                   |
| `history.png`    | вкладка «История»        | Режим «30 дней», чтобы хитмап был заполнен; в правой колонке выбран день с расходом                                            |
| `settings.png`   | «Настройки → Приложение» | Виден автозапуск и строка версии с состоянием обновления                                                                       |

Первых двух хватает для README — они уже в него вставлены. Остальные три
пригодятся странице релиза и продуктовым текстам; без них README не ломается.

Чего на снимках быть не должно: чужих имён проектов и веток, если они закрытые
(для этого в настройках есть «скрыть пути к файлам»), и первых промптов с
рабочей перепиской (тумблер «скрыть тексты промптов»). Проверить проще всего
так: снять, посмотреть на картинку глазами, а не на приложение.
