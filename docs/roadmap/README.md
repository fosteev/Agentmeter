# Брифы этапов

Здесь лежат брифы — по одному на этап, который вот-вот пойдёт в работу.
Каждый файл самодостаточен: его можно отдать исполнителю целиком, без чтения
остальной документации.

## Правила, чтобы это не сгнило

1. **Статусы живут только в [`../roadmap.md`](../roadmap.md).** Здесь их нет.
   Два места со статусами разъедутся на второй неделе — проверено человечеством.
2. **Бриф пишется на веху вперёд, не дальше.** Этапы M3–M4 перепишутся после
   того, как M1 покажет, где я ошибся в модели данных. Писать их сейчас —
   сочинять фантазии с видом занятости.
3. **Нет брифа — нет делегирования.** Если задачу нельзя описать по шаблону,
   значит она недостаточно понята, чтобы её отдавать.
4. **Бриф удаляется вместе с закрытием этапа.** Что осталось от работы —
   код и тесты, а не описание намерений. В git история сохранится.

## Шаблон

См. [`_template.md`](_template.md). Четыре обязательных раздела — файлы,
контракт, критерий, данные. Без любого из них Codex сочинит недостающее сам
и отрапортует об успехе.
