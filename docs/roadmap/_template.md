# N.N — название этапа

**Кто:** сам / Codex · **Объём:** S / M / L · **Блокирует:** какие этапы ждут этот

Одним абзацем: зачем этот этап нужен и что сломается, если сделать его плохо.

## Файлы

Что создаём и что править нельзя. Перечислять поимённо — «в районе core»
не годится, исполнитель разойдётся по всему репозиторию.

```
создать:   packages/core/src/...
не трогать: packages/core/src/sources/types.ts
```

## Контракт

Типы, схемы, сигнатуры, которые уже заданы и меняться не могут. Со ссылкой на
файл, где они лежат, а не пересказом.

## Критерий готовности

Команда. Не «работает корректно», а строка, которую можно выполнить.

```bash
npm test -w packages/core -- claude
```

## Данные

Фикстуры, макет, эталон — то, с чем сверяться. Без этого пункта результат
проверить нечем, и любая цифра сойдёт за правильную.

## Подводные камни

Что уже известно про грабли на этом участке. Раздел не для красоты: сюда
уходит всё, что выяснилось разведкой, иначе исполнитель наступит заново.
